# 我的文档：前端接入

2026-10-07，用户确认接口上传与正文查询可用后，授权将其接入原前端。

## 使用

启动四项基础服务、API 和 Worker（步骤见 BACKEND-STATUS.md），再在根目录执行 `npm run dev`。打开 http://127.0.0.1:5173/ ，进入系统后点击顶部「我的文档」。选择文件并上传，左侧显示最近 100 份文档及处理状态，右侧显示提取的正文。窗口打开时自动刷新，关闭后停止请求，重开可继续查看后台处理结果。

单文件上限 20 MiB，不接受空文件。上传期间阻止重复提交和关闭窗口；异常中断后提示先刷新列表确认是否已保存，避免重复上传。2026-10-15 已增加原始 PDF 预览、原件下载和文件名/正文搜索；图片 OCR、手动重新提取、删除、鉴权和带索引的全文检索仍未实现。

## 接入边界

- 原生 TypeScript 面板 `src/apex-documents.ts`，样式独立；复用既有弹窗过渡、背景输入隔离、Escape、焦点循环和关闭后焦点恢复。现有 40 份三维档案保持原用途，上传文档不替换其编号或内容。
- 仅在开发模式自动显示入口。普通静态和 Wallpaper Engine 构建不显示入口；要为独立 APEX 部署开启入口，构建时显式设置 `VITE_APEX_ENABLED=true`，并先提供同源 `/api` 网关。尚未将本功能部署到正式网站。
- 浏览器仅请求同源 `/api/documents`。Vite 在本机 5173 将 `/api` 代理至 127.0.0.1:3000，端口被占用时明确失败，不悄悄改号。API、Worker 仍须分别启动。
- GET 请求禁用缓存，既有 Service Worker 只缓存发行资源白名单，不缓存文档接口。正文不存入 localStorage。
- 文件名与正文通过 `textContent` 写入，不解释 HTML。处理结果刷新不会替换已完成正文节点或重置滚动位置。关闭面板取消查询并使迟到响应失效。
- 窄屏采用上下布局和独立正文滚动；面板开启时固定舞台使用 `overflow: clip`，防止浏览器在窗口变窄时滚动舞台去追踪焦点。

## 真实三维档案（2026-10-15）

1. 在「我的文档」上传 PDF，选中文档后点击「在三维档案中查看」。也可从顶部「真实档案」进入 `/?library=documents`。
2. 页面从后端分批读取真实元数据，使用 `D-001` 形式的数据库稳定编号进入原三维交互。点击 ACCESS FILE，沿用抽取、解密与详情过渡，正文处理未完成时自动刷新。
3. 详情中的 OPEN DOCUMENT 在新标签页用浏览器 PDF 阅读器显示原始 PDF；「下载原件」保留原始字节和中文文件名。其他格式可阅读提取文字或下载，尚无 Office 转 PDF。
4. 「我的文档」支持搜索文件名、标题和提取正文，包括中文；最多显示最近 100 个匹配结果。真实三维目录通过游标逐页加载，不限制为最近 100 份。
5. 三维目录为进入页面时的快照，新上传后使用文档跳转链接或「刷新真实档案」重新载入。原演示保持 `/` 入口，收藏分别使用 `apex-saved` / `rhine-saved`，均只存在本浏览器。

五列目前按 PDF、Word、表格、演示文稿、其他文件分组，只是首版导航，不代表已确定工程知识业务分类。每列实际数量可变；刻度只呈现当前附近的最多八项，键盘和拖动仍可循环选取全部文档。空分类显示「此分类暂无文档」和 00，不生成数据库伪文档，禁用读取并排除搜索/收藏。

数据适配由 `src/bootstrap.ts`、`src/document-api.ts` 和 `src/document-archive.ts` 完成；三维代码仅调整编号、选档定位与不同列长度的共同循环周期，不修改模型、材质、相机与动效参数。PDF 当前采用浏览器原生阅读器，蓝图中的 PDF.js 内嵌阅读器留待下一阶段按阅读需求接入。无阅读器的浏览器可能下载 PDF。

验证脚本 `node --experimental-strip-types scripts/check-document-archive.mjs` 覆盖稳定编号、35 PDF / 10 Word、空列、超过 32 行的映射与循环坐标重置。`scripts/check-apex-archive.cjs` 使用真实 API/Worker/MinIO，创建并清理本轮测试文档，覆盖 34 份 PDF、实际浏览器上传和深链接选档、正文、PDF 阅读器、原件字节、Range/416/404、非 PDF 预览拒绝、收藏、空列、切列记忆、中文搜索、游标和演示入口。设置 `APEX_FULL_MOTION=1` 验证完整动效；默认减少动态效果。截图复核修正了详情焦点导致的舞台横向偏移。窄屏仍为桌面 Chromium 模拟，不等同 iPhone 验收。
